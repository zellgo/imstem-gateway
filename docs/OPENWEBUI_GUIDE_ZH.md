# Open WebUI 界面与知识库使用指南

面向：ImStem 医学、监查、项目管理同事  
地址：[https://chat.imstem.org](https://chat.imstem.org)  
版本：Open WebUI **v0.11.1**  
更新日期：2026-08-30

本指南只讲网页对话。Codex / Claude Code / Python 见 [USER_GUIDE_ZH.md](USER_GUIDE_ZH.md)。

界面语言可能是英文。下文同时写 **中文习惯说法** 和 **界面英文**。右下角头像 → **Settings / 设置** → **General** 可把界面改成中文。

---

## 1. 登录

1. 打开 [https://chat.imstem.org](https://chat.imstem.org)
2. 用入职邮件里的 **公司邮箱 + 密码**（不是工号，也不是阿里云账号）
3. 登录后应能在左上角看到模型列表（`qwen3.8-flash` 等）

看不到模型：按 `Ctrl + Shift + R` 硬刷新，或退出再登录。仍没有，找管理员。不要自己去「连接 / Connections」里贴阿里云或小米官方 Key。

## 2. 界面长什么样

从左到右可以分成三块。

### 2.1 左侧栏

| 你会看到 | 做什么 |
|---|---|
| **New Chat / 新对话** | 开一个空白聊天 |
| 历史对话列表 | 点开以前的对话 |
| 文件夹（Folders） | 把同一项目的对话归到一起，也可绑知识库 |
| **Workspace / 工作空间** | 知识库、提示词、自定义模型、技能、工具 |
| 底部头像 | 设置、账号、退出 |

### 2.2 中间主窗口（聊天）

- **左上角**：当前模型名称，点开可换模型
- **中间**：对话内容
- **底部输入框**：打字、粘贴、拖文件、发消息
- 输入框左边 **+** 或回形针：上传文件、截图、引用知识库

### 2.3 建议的第一次设置

1. 左上角模型选 `qwen3.8-flash`（默认、便宜）
2. 头像 → **Settings** → **General**：语言选中文（可选）
3. 不要改 **Connections / 连接** 里的网关地址和密钥

选模型口诀和单价见 [USER_GUIDE_ZH.md](USER_GUIDE_ZH.md)、[MODEL_COST_ZH.md](MODEL_COST_ZH.md)。

## 3. 日常聊天怎么用

### 3.1 发一条消息

1. 点 **New Chat**
2. 确认左上角模型
3. 在底部输入问题，回车或点发送
4. 等右侧/下方出现回答（流式输出时字会一个个出来）

### 3.2 换模型

点左上角模型名，选：

- 草稿、翻译、纪要、访视报告套话 → `qwen3.8-flash`
- 方案章节、SOP → `qwen3.8-27b`
- 法规对读、很难的医学论证 → `qwen3.8-max`
- 不要把 `kimi-k3` 当聊天默认（最贵）

同一条对话中途换模型可以，但长对话建议新开一个 Chat，避免把旧上下文全部再计费一遍。

### 3.3 这条消息上的常用按钮

回答下方一般有：

| 操作 | 作用 |
|---|---|
| 复制 | 拷贝回答 |
| 重新生成 / Regenerate | 用同一问题再答一次 |
| 编辑 | 改你刚发的那句，再提交 |
| 朗读（若开启） | 读出回答 |

左侧历史里，对话标题可点铅笔改名；点垃圾桶删除。

### 3.4 临时塞一个文件（不做知识库）

适合「就这一次问这份 PDF」：

1. 把文件拖进输入框，或点 **+** → 上传
2. 等文件处理完成（出现文件卡片）
3. 再提问，例如：「用三条归纳这份访视报告的主要发现」

支持常见格式：PDF、Word（.docx）、TXT、Markdown、CSV、部分表格。扫描件纯图片 PDF 可能抽不出字，需要先 OCR。

**和知识库的区别：** 聊天里拖的文件只属于这一场对话；知识库可以跨很多场对话反复用。

### 3.5 对话文件夹（项目）

适合「这个试验 / 这个方案相关的聊天都放一起」：

1. 左侧历史上方或空白处，创建 **Folder**
2. 把对话拖进去，或先点文件夹再 **New Chat**
3. 文件夹设置里可以：写一段固定系统提示、**挂上知识库**  
   以后这个文件夹里的新对话都会自动带上那些文档

## 4. 知识库是什么

知识库（界面：**Workspace → Knowledge**）把 SOP、方案、法规摘录、模板等存成「可搜索的资料柜」。

提问时，系统先从资料柜里找出相关段落，再交给大模型回答。这叫 **RAG（检索增强）**。模型不是把 200 页方案整本每次都塞进去，而是抽相关几段，所以又省钱、又不容易编造条款编号。

| 方式 | 适合 | 不适合 |
|---|---|---|
| 聊天里临时拖文件 | 一次性 | 同一份方案要反复问 |
| **知识库** | SOP、方案、模板、法规摘录，要复用 | 可识别患者病历 |
| 笔记 Notes | 短的、必须全文都看见的风格说明 | 大部头 PDF |

## 5. 创建知识库（逐步）

界面英文是 **Workspace → Knowledge**；中文界面常译成 **工作空间 → 知识库**。

### 5.1 新建

1. 左侧点 **Workspace / 工作空间**
2. 上方标签选 **Knowledge / 知识库**
3. 右上角点 **Create / 创建**（有的版本是 **+**）
4. 填写：
   - **名称**：短、好认，例如 `MED-SOP-监查`、`方案-XX试验`
   - **描述**：写给同事看的，例如「CRA 访视报告模板与发现分级」
5. 保存。列表里应出现这条知识库

建议按 **项目或文档类型** 拆，不要把全公司所有 PDF 丢进一个库。检索会更准，权限也好管。

ImStem 可参考的拆法：

| 知识库名称示例 | 放什么 |
|---|---|
| `SOP-监查` | 监查 SOP、query 规范、TMF 清单 |
| `方案-某某试验` | 方案正文、方案修订、入排标准摘录 |
| `公文模板` | 纪要、周报、邮件口径（去标识后） |
| `公开法规` | 已公开的 ICH / 药监技术指导原则 |

### 5.2 往里面加文件

打开刚建的知识库：

1. 点 **Add Content / 添加内容**（或 **+**）
2. 选 **Upload / 上传文件**（可多选）
3. 等处理完成。状态会从处理中变成可用。  
   **没处理完就提问，模型会说找不到或答得很空。**

还可以：

- **+ New Directory / 新建目录**：在库里建子文件夹（如 `v1.2方案`、`培训`）
- 把文件拖到目录上，整理结构
- 点文件右侧 **⋯**：**重命名**（不必重新上传）
- **Sync Directory / 同步本地目录**（浏览器里对照本地文件夹，只上传新增/修改的文件；文件特别多时会较慢）

把公开网页贴进输入框时，若链接指向 PDF/图片，新版本会尝试下载原文件再入库；普通网页则抽取页面文字。

### 5.3 建议的文件形态

效果好：

- 可选中文字的 PDF、Word、Markdown、TXT
- 一文件一个主题（「入排标准」单独一份，比整本方案更好检索）
- 文件名写清楚：`XX试验-入排标准-v1.2.pdf`

效果差：

- 扫描件、照片 PDF（没有文字层）
- 密密麻麻的双栏扫描、水印压字
- 把未脱敏病历、姓名、住院号、身份证放进来（**禁止**，见第 8 节）

## 6. 对话里怎么用知识库

有三种用法，从临时到固定。

### 6.1 最常用：输入框打 `#`

1. 开一个 **New Chat**，选好模型
2. 在输入框输入 **`#`**
3. 弹出列表：知识库、以及库里的文件
4. 选整个知识库，或只选其中一个文件
5. 输入框上方出现附件卡片，再输入问题

示例提问：

- 「根据已引用的方案，列出排除标准，用原编号。」
- 「对照 SOP，这份访视发现应该定哪一级？列出依据段落。」
- 「不要发挥。资料里没有就写『资料未记载』。」

点附件卡片，可在两种检索方式间切换：

| 模式 | 界面常见名称 | 什么时候用 |
|---|---|---|
| **Focused Retrieval / 聚焦检索** | 默认 | 库很大、只要相关几段（省钱、推荐） |
| **Full Context / 完整上下文** | 把全文塞进每一轮 | 很短的模板、必须逐字引用的风格说明 |

长方案不要用 Full Context，又贵又容易把对话挤爆。

### 6.2 绑到文件夹

某个试验的所有聊天都要看同一套方案：

1. 建文件夹，例如 `试验-XX`
2. 文件夹设置 → **Attach Knowledge / 附加知识**
3. 选该试验的知识库
4. 先点这个文件夹，再 **New Chat**

之后这个文件夹里的新对话会自动带上知识库。

### 6.3 绑到自定义模型（管理员或会建模型的人）

**Workspace → Models → Create / Edit**：选一个基础模型（如 `qwen3.8-27b`），在知识一项里挂上知识库，保存成例如「监查助手」。之后左上角模型列表里可以直接选它，不必每次打 `#`。

注意：v0.11 默认会让模型 **自己决定何时去搜知识库**（工具调用）。如果模型答得很泛、不像在看文档，见第 7 节。

## 7. 怎样问，答案才像「根据我们的文件」

知识库不是自动保证「只根据 PDF 回答」。提问方式影响很大。

**好问法：**

- 「仅根据当前引用的知识库回答。没有依据就说资料未记载。」
- 「引用原文条款编号，不要改写编号。」
- 「对比方案 8.2 节和 SOP 第 4 章，列出不一致。」

**差问法：**

- 「你觉得我们应该怎么做？」（模型容易用通用知识编）
- 不打 `#`、不绑库，却指望它「记得上周传的方案」

回答里若出现引用角标 / 来源卡片，点开可核对原文。对法规和方案，**以原文为准，模型只是草稿**。

若模型完全不查库：

1. 确认 `#` 附件还在，文件已处理完成
2. 系统提示里加一句：「先检索知识库再回答，禁止编造条款。」
3. 短文档可把附件改成 **Full Context**
4. 仍不行，换 `qwen3.8-27b` 或 `qwen3.8-max` 再问一次（Flash 有时检索指令执行较差）

## 8. 可以放 / 不可以放

和聊天规则相同，知识库更要小心，因为文件会留下来、可能被多次检索。

| 可以入库 | 不要入库 |
|---|---|
| 已去标识的方案、SOP、模板 | 可识别患者信息（姓名、住院号、身份证、影像号） |
| 公开法规、已发表论文 | 密码、同事 API Key、未脱敏病历 |
| 内部流程（按公司保密规定） | 未批准对外的法律意见全文（按法务要求） |

临床内容：先去标识再上传。知识库回答不能替代医学、法规或统计签字。

## 9. 权限、共享、整理

- 新建知识库时注意 **可见范围**（仅自己 / 组内 / 公开）。不确定就先仅自己，再请管理员共享。
- 同事要共用同一套 SOP：由一人维护主知识库，其他人用 `#` 引用；不要每人传一份重复文件。
- 改了方案版本：上传新文件并在文件名加 `v1.3`，旧版移到目录 `归档` 或删除，避免模型混用两个版本。
- 管理员可从知识库 **⋯ → Export** 导出备份（普通用户不一定能看到导出）。

删除文件会让以后的检索再也找不到它；已经生成的旧聊天文字还在，但无法再从该文件抽新段落。

## 10. 费用（知识库也会花钱）

检索本身通常比「把整本方案贴进 Max」便宜，但仍会：

1. 处理/嵌入文件（上传时一次）
2. 每次提问把检索到的段落送给聊天模型（按该模型 Token 计费）

建议：

- 检索问答默认 `qwen3.8-flash` 或 `qwen3.8-27b`
- 不要对一个大库开 Full Context + `kimi-k3`
- 同一主题连续问，用同一场对话（缓存更便宜）；换主题就 **New Chat**

单价见 [https://llm.imstem.org/costs](https://llm.imstem.org/costs)。

## 11. 常见问题

**Q：上传后提问说没有内容？**  
A：等文件状态变成已处理。扫描 PDF 没有文字层，需要先转成可选中文本。

**Q：答案和 PDF 对不上。**  
A：点引用核原文。可能检索到旧版本文件。把旧版归档，提问时写「仅使用 v1.3」。

**Q：`#` 没有弹出知识库？**  
A：确认已保存在 **Workspace → Knowledge**，不是只拖进了某一场聊天。刷新后再试。

**Q：知识库和左侧「笔记 Notes」有何不同？**  
A：笔记适合短文、会把全文塞进对话；知识库适合多份长文档、按问题抽段落。

**Q：能否把知识库给 Codex 用？**  
A：网页知识库只在 chat.imstem.org 里。Codex 用的是 AGENT 密钥，看不到这里的知识库。需要的话把同一份去标识文件放在本地项目里给 Codex 读。

**Q：登录后模型是空的？**  
A：硬刷新。不要改 Connections。找管理员。

## 12. 五分钟走一遍（建议每人做一次）

1. 登录 [https://chat.imstem.org](https://chat.imstem.org)
2. 选 `qwen3.8-flash`，问一句「用三句话说明间充质干细胞」确认能聊
3. **Workspace → Knowledge → Create**，建 `练习-公开法规`（只放已公开文件）
4. 上传一份无患者信息的 PDF，等到处理完成
5. **New Chat**，输入 `#`，选这个库
6. 问：「根据引用资料，列出三个要点，并注明是否来自原文。」
7. 核对引用。确认无误后可删掉练习库，再建正式的项目库

出问题找网关管理员。不要把密钥或未脱敏文件发到微信群。
