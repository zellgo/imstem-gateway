## 1. 公司结论（先看这张）

小团队要控成本，推荐 **三级梯子**，不要八个模型平铺着用。

| 档 | 模型 | 谁用、干什么 | 相对 Flash 的大致费用 |
|---|---|---|---|
| **默认（80–90% 流量）** | `qwen3.8-flash` 或 `glm-5.3-flash` | 全员日常：翻译、润色、纪要、邮件、访视报告、清单。两档同级，可自由切换 | 千问 Flash = 1×；GLM Flash ≈ **0.4×**（更便宜） |
| **写作** | `qwen3.8-27b` | 方案章节、SOP、发现归纳、风险描述 | 约 **4×** |
| **难题** | `qwen3.8-max` | 法规对读、科学逻辑、长文档一次吃透 | 约 **14×** |
| **代码 / Agent** | `mimo-v2.5-pro` | Codex、脚本、多步工具 | 约 **3×**（远低于 Kimi） |
| **不要当默认** | `kimi-k3` | 仅当 MiMo Pro 与 Max 都失败 | 约 **30×** |
| 备选便宜推理 | `deepseek-v4-flash-0731` | Flash 排队或效果差时 | 闲时约 2×，忙时约 4× |
| 备选强推理 | `deepseek-v4-pro-0813` | 要推理、又不想上 Max/Kimi | 闲时约 5×，忙时约 11× |
| 备选便宜多模态 | `mimo-v2.5` | 看图/轻量 Agent，中文公文仍优先千问 | 约 1× |

**管理规定建议：**

1. 新人默认模型设为 `qwen3.8-flash` 或 `glm-5.3-flash`（同级，可随时换）。
2. Codex / Claude Code **写明网关模型名**。网关不会把 `gpt-4o` 转到 `kimi-k3`，也不会在额度用尽时改走别的模型。
3. `kimi-k3` 不作聊天默认；只用于别的模型都失败的长程 Agent。
4. 试用期也走梯子：免费额度烧在 Max/Kimi 上，额度会很快没，后面立刻开始付费。

## 4. 按任务怎么选

| 任务 | 用 | 不要用 |
|---|---|---|
| 邮件、纪要、翻译、润色、清单、访视报告套话 | `qwen3.8-flash` 或 `glm-5.3-flash`（同级可换） | Max / Kimi |
| 方案/SOP 某一章、发现归纳、风险描述、PPT 大纲 | `qwen3.8-27b` | 把整本材料反复塞进 Max |
| 法规条款对读、科学机制说不清、审稿意见很难写 | `qwen3.8-max`（一两次即可） | 用 Kimi 写中文公文 |
| 脚本、表格清洗、Codex、多步工具 | `mimo-v2.5-pro` | 默认 `kimi-k3` |
| 别的模型都失败的长程 Agent | 再试 `kimi-k3` | 日常聊天 |
| 可识别患者信息、身份证、未脱敏病历、影像号 | **禁止进任何模型** | — |

翻译和润色走 Flash 档，否则额度会先被草稿吃光。难题才升 27b / Max。

## 5. 为什么不推荐「全都用最好的」

1. **Kimi K3 输出 100 元/百万**，是 Flash 输出价的约 37 倍。Agent 会吐很长的思维链，费用按输出计，最伤。
2. **Max 12/36** 适合「一篇难文」，不适合「一天五十封邮件」。
3. **DeepSeek 快照忙时**接近 Max，却没有千问的中文公文优势；工作时间优先千问。
4. **免费试用不是无限。** 试用期用 Max 刷长文档，额度结束当天账单会跳起来，团队还没养成选模型习惯。
5. 生物医药的质量风险在「胡编法规/疗效」，不在「模型不够旗舰」。Flash + 人工审核，比 Max 无审核更安全、更便宜。

## 6. 建议的公司默认（可当制度贴出去）

1. Open WebUI 默认模型：`qwen3.8-flash` 或 `glm-5.3-flash`（同级，日常写作自由切换）。
2. 写作升级顺序：Flash 档（千问或 GLM）→ 27b → Max。跳级要能说出理由（例如「27b 把入排标准理解错了」）。
3. 编程默认：`mimo-v2.5-pro`；禁止依赖 GPT/Claude 别名（会落到 Kimi）。
4. `kimi-k3`：不进推荐默认；只在长程 Agent 连续失败时用。
5. 工作日白天 DeepSeek Pro 快照尽量不用。
6. 单次粘贴超过约 2 万字：先 Flash 摘要，再把摘要和争议段落给 27b/Max。
7. 试用额度用尽后：不改梯子，只是开始从账户扣费；管理员在 LiteLLM 看各 `*-CHAT` / `*-AGENT` 消耗。

按上述执行，试用结束后正常办公（Flash 档为主、少量 27b/Max、偶发 MiMo Pro）月费通常可控制在团队 **数百元人民币** 量级；若默认 Kimi Agent，仅代码通道就可能到 **人均数百、团队数千**。
