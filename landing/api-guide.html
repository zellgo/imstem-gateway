ImStem LLM

个人 API 使用说明

每人一把 LiteLLM 虚拟密钥。它不是阿里云或小米的官方 Key，只在 https://llm.imstem.org 上有效。用量记在你的工号上。

关键工具

Windows 上把 ChatGPT / Codex / Claude Code 切到公司密钥，用 CC Switch，不要只靠手改配置文件。

CC Switch 官方中文站下载。添加 ImStem 时，地址栏叫 API Request URL（不是 Base URL）：Codex 填 https://llm.imstem.org/v1，Claude Code 填 https://llm.imstem.org（不要加 /v1）。API Key 用邮件里的 AGENT 密钥。默认模型：先点输入框右边下载按钮拉取可用模型，选要用的，再 Save。 ccswitch.io/zh · 公司推荐

完整步骤见员工指南 §5.2 CC Switch。CC Switch 具体可参照 官网使用指南。

1. 网页对话

  1. 打开 https://chat.imstem.org
  2. 用邮件里的 Open WebUI 邮箱和密码登录
  3. 在模型列表里选下面的名字（不要选 GPT / Claude 的原名；那些会被网关转到 Kimi K3）

3. OpenAI 兼容（Codex / OpenCode / Python）

Base URL 必须带 /v1。把邮件里的 AGENT 密钥填进去。

export OPENAI_BASE_URL=https://llm.imstem.org/v1
export OPENAI_API_KEY=sk-你的AGENT密钥

curl https://llm.imstem.org/v1/chat/completions \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen3.8-flash",
    "messages": [{"role":"user","content":"用一句话介绍间充质干细胞"}]
  }'
from openai import OpenAI
client = OpenAI(
    base_url="https://llm.imstem.org/v1",
    api_key="sk-你的AGENT密钥",
)
print(client.chat.completions.create(
    model="qwen3.8-max",
    messages=[{"role":"user","content":"Hello"}],
).choices[0].message.content)

4. Codex / ChatGPT 桌面版

推荐：用 CC Switch 添加 ImStem 供应商（见页顶「关键工具」和 员工指南 5.2）。手改配置在 Windows 桌面版上经常被沙盒窗口挡住。

地址栏在 CC Switch 里叫 API Request URL，Codex 填 https://llm.imstem.org/v1。默认模型先点输入框右边下载按钮拉取列表，再选 qwen3.8-flash 等网关名字，Save。每次切换供应商或切回 OpenAI 官方后：任务管理器搜索 chatgpt，结束全部进程，再开桌面版。

# 仅在不用 CC Switch、自己改 CLI 时：~/.codex/config.toml
model = "qwen3.8-flash"
model_provider = "imstem"

[model_providers.imstem]
name = "ImStem"
base_url = "https://llm.imstem.org/v1"
env_key = "OPENAI_API_KEY"
wire_api = "responses"

如果仍发送 gpt-4o / gpt-5 / gpt-5.4，公司密钥会 403，或被网关转到 kimi-k3（最贵）。费用仍记在你名下。

5. Claude Code

ANTHROPIC_BASE_URL 不要加 /v1，Claude Code 会自己拼 /v1/messages。

export ANTHROPIC_BASE_URL=https://llm.imstem.org
export ANTHROPIC_API_KEY=sk-你的AGENT密钥
export ANTHROPIC_MODEL=kimi-k3
// ~/.claude/settings.json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://llm.imstem.org",
    "ANTHROPIC_API_KEY": "sk-你的AGENT密钥",
    "ANTHROPIC_MODEL": "kimi-k3"
  }
}

6. 不要做的事

  • 不要把阿里云 / 小米官方 Key 写进任何本地工具
  • 不要把你的虚拟 Key 转给同事
  • 不要上传可识别的患者信息、密码、未脱敏病历

问题找网关管理员。Key 失效通常是轮换或月度额度用完。
