ImStem LLM

个人 API 使用说明

每人一把 LiteLLM 虚拟密钥。它不是阿里云或小米的官方 Key，只在 https://llm.imstem.org 上有效。用量记在你的工号上。

1. 网页对话

  1. 打开 https://chat.imstem.org
  2. 用邮件里的 Open WebUI 邮箱和密码登录
  3. 在模型列表里选下面的名字（不要选 GPT / Claude 的原名；那些会被网关转到 Kimi K3）

2. 可选模型

模型名适合上游
qwen3.8-flash快、便宜，草稿翻译阿里云百炼
qwen3.8-27b日常写作修改阿里云百炼
qwen3.8-max难文、长文档阿里云百炼
kimi-k3Agent、代码、Codex 默认阿里云百炼
deepseek-v4-flash-0731低成本推理阿里云百炼
deepseek-v4-pro-0813更强 DeepSeek V4阿里云百炼
mimo-v2.5小米 2.5Xiaomi MiMo
mimo-v2.5-pro小米 2.5 ProXiaomi MiMo

3. OpenAI 兼容（Codex / OpenCode / Python）

Base URL 必须带 /v1。把邮件里的 AGENT 密钥填进去。

export OPENAI_BASE_URL=https://llm.imstem.org/v1
export OPENAI_API_KEY=sk-你的AGENT密钥

curl https://llm.imstem.org/v1/chat/completions \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen3.8-flash",
    "messages": [{"role":"user","content":"用一句话介绍间充质干细胞"}]
  }'
from openai import OpenAI
client = OpenAI(
    base_url="https://llm.imstem.org/v1",
    api_key="sk-你的AGENT密钥",
)
print(client.chat.completions.create(
    model="qwen3.8-max",
    messages=[{"role":"user","content":"Hello"}],
).choices[0].message.content)

4. Codex

# ~/.codex/config.toml
model = "kimi-k3"
model_provider = "imstem"

[model_providers.imstem]
name = "ImStem"
base_url = "https://llm.imstem.org/v1"
env_key = "OPENAI_API_KEY"
wire_api = "chat"

如果 Codex 仍然发送 gpt-4o / gpt-5，网关会转到 kimi-k3，费用仍记在你名下。

5. Claude Code

ANTHROPIC_BASE_URL 不要加 /v1，Claude Code 会自己拼 /v1/messages。

export ANTHROPIC_BASE_URL=https://llm.imstem.org
export ANTHROPIC_API_KEY=sk-你的AGENT密钥
export ANTHROPIC_MODEL=kimi-k3
// ~/.claude/settings.json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://llm.imstem.org",
    "ANTHROPIC_API_KEY": "sk-你的AGENT密钥",
    "ANTHROPIC_MODEL": "kimi-k3"
  }
}

6. 不要做的事

  • 不要把阿里云 / 小米官方 Key 写进任何本地工具
  • 不要把你的虚拟 Key 转给同事
  • 不要上传可识别的患者信息、密码、未脱敏病历

问题找网关管理员。Key 失效通常是轮换或月度额度用完。
